# 画面规格与工具

以下数值来自已确认的 1080 × 1920 成片，可按新素材的面部大小和平台安全区等比调整。

- 人像小窗直径约 202 px，距右约 58 px、距顶约 108 px；裁入头肩。优先右上；若一组画面右上有重要证据，检查右下操作区，整组换位。小窗轨直接取与成片同时间轴的干净人物母版。口播有删节时，先把相同的删节和速度变化应用到这条轨。底层第 8 秒应显示母版第 8 秒的口型。
- 数字参考 Bahnschrift Bold，字宽轴约 86，替代字体可选 Barlow Condensed Bold 或外形相近的粗窄无衬线。中文标题可用思源黑体 / Noto Sans SC 800–850 字重。大数字顶部 #FFDE95、中段 #FFC356、底部 #FF9E01。日期字面高度约 250–280 px；并列门槛约 190–220 px；单位约为主数高度的 25–40%。根据字符长度缩放整组，避免字间挤压。无描边、无字形投影，必要时给底图局部压暗。
- 单一日期可居中。两项门槛可以分列，上方给出“收入不低于”“同比增长”等准确标签。口播字幕白色无衬线，每行通常约 49–55 px 字面高；旧片字幕在约 81% 画高，发布前检查右侧按钮和底部说明。
- 横版素材优先重构竖屏动作中心；裁掉关键关系时保留原画比例，把空余空间用来放出处或一句解释。低清截图先找高分辨率原件。公文的正文保留原始排版风格。

**金色数字图层。** 使用 Pillow 脚本生成紧边界透明 PNG，贴在剪辑工程中的目标位置。参数以字面的像素高度计算，支持日期、小数、负号和独立单位。含中文单位时提供覆盖该字的字库。变量字体支持字重及字宽轴。先预览实际字形。

```text
python scripts/gold_number.py 08.31 date.png --font "C:/Windows/Fonts/bahnschrift.ttf" --height 278
python scripts/gold_number.py 100 amount.png --font "C:/Windows/Fonts/bahnschrift.ttf" --height 220 --unit 万元 --unit-font "C:/Windows/Fonts/msyhbd.ttc"
```

**同步圆窗。** 先完成并导出无圆窗的 B-roll 合成片与同时间轴的人物母版。下列参数指定的是示例素材中的脸部方形裁区（源像素）和 B-roll 的起止时间（成片秒数，左闭右开）。换片后重新定位人脸、重填区间。用 ffprobe 或剪辑器检查两条输入轨已按显示方向归正、像素宽高比为 1，且起点、剪辑和速度一致。工具需要可执行的 FFmpeg、ffprobe 和 Pillow。用 `--corner br` 改到右下，若多个素材组需不同位置可在剪辑器分段放置。

```text
python scripts/presenter_pip.py assembled.mp4 speaker-clean.mp4 with-pip.mp4 --crop 170,380,700 --ranges 1.24-2.96,4.80-6.80,7.52-20.44
```

**复核。** 取每个进出小窗前一帧、切点和后一帧，检查小窗只在指定段落出现；抽取至少三处口型，和母版同时间码对照。看读数是否挤压、渐变底色是否与背景混在一起、原文高亮是否挡字。先在手机大小看一遍，再放大全屏验文字。
