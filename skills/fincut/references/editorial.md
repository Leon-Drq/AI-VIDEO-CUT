# 镜头与声音

| 台词要解决的问题 | 搜什么、从哪里取 | 怎么剪 |
| --- | --- | --- |
| 哪家公司做了什么产品 | 企业官方媒体包、官网演示、产品实物、用户给的实机录像 | 第一次出现专有名词时给能辨认的标识或产品全貌；再切操作细节。 |
| 资金、收入或毛利怎么变了 | 财报对应页、交易所披露、可核验的统计表 | 核对期间、币种、分母和同比/环比。高亮两列或用共享基准作图。把出处留在画面可读的位置。 |
| 文件究竟要求什么 | 发布机构原始通知、附件 PDF、公开申报材料清单 | 先定位文件和发布者，再放大一句。对地区、批次、主体和例外保留必要限定。下载了原件后打开验证页码和清晰度。 |
| 人在做什么、流程堵在哪一步 | 客户现场或许可实拍。试搜“档案柜 取文件夹 手部”“hands retrieving binder close-up”“wafer inspection cleanroom” | 看完整动作、挑起手帧与落点。动作镜头说明劳动过程；后台审计数字用披露或表格说明。 |
| 抽象机制如何运作 | 原始产品录像、器件特写、实测或原创简图 | 用一个对象演示前后状态；进入下一步只变当前变量。类比之后切回真实对象，指明二者的对应点。 |

优先在用户资产、发布机构及企业公开资料中找特定对象。可在 Pexels 等有明确条款的库里找匿名情境实拍；记录作者、素材页、许可条件及剪取范围。企业媒体图、新闻和网页根据具体用途核对使用条件。避免直接复用参考视频片段、品牌包装和音乐。缺少特定厂区现场时，按实际情况注明行业示意。

把人声剪干净后再配乐。讲话段音乐可从低于人声约 18–24 dB 起听，按不同音源实际调节。纸页翻起再落下，音效选同方向、同质感的一声；键盘、钟表和计算器各有不同的瞬态。手机扬声器再听一遍，确认音效未盖住辅音；检查编码后整体响度和真峰值。示例终版约 −17 LUFS、−1.5 dBTP，可作试听参照。需要署名的曲目保留作者、曲名、许可链接及剪混说明。

**参考片的节奏观察。** 工厂蒙太奇约 5.4 秒用了五个实拍镜头；三步流程图约 9.6 秒，变化来自逐项建立与高亮。同一张图可以在画面上停留到一个关系解释完。套用到新片时，先确定观众在辨认对象、理解关系还是听判断，再决定切换频率。
