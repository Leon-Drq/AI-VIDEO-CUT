# 证据镜头和动效

## 重点词起音时推近

在最终语速的音轨上找到重点词的首字和重读字，用听到的起音或经核对的字级时码落关键帧。一条字幕可能包含整句话，字幕出现时刻只能帮助定位。以双眼附近为缩放中心，真人画面与人物遮罩共用同一组变换，标题和字幕留在原位置。

以「历史性一刻」为例，定稿选中的是「历史」。25 fps 下，第 0 帧「历」起音时用原景别，第 6 帧（0.24 秒）到「史」时放大至 118%，中间平滑过渡，后面的「性一刻」保持近景。其他口播按实际重音间隔定时，按脸部景别、发顶和手势余量定幅度。

当下一处重点转为数字时，将强调交给数字与单位，真人可以自然退场。开声音连播首句，核对起音和到位两个落点；逐帧看起推、途中、停稳三个位置，确认眼神稳定、标题可读，数字和单位与素材边缘有间距。

## 找到能说明这句话的画面

| 口播落点 | 建立主体 | 观众接着看什么 |
| --- | --- | --- |
| 人物、机构或产品 | 可辨认的真人照片、原版 Logo 或实物 | 用出自其本人的文稿或实际演示说明角色；相同名称无须再占一行大字 |
| 一份文件确认了什么 | 显示文件标题、发布者与日期 | 从同份资料取出关键句，保留限定词。自行排版的引述标为“节录／译文”，影像重建标明示意 |
| 一个数字有多大 | 显示总量、单位和时间范围 | 对准真实行、柱或区间。用实物比喻时保留估值、股份、现金、计划之间的区别 |
| 两个案例效果如何 | 选择相同任务、动作起点、景别，先交代各自身份 | 同步到结果落点，给观众看差异的时间。左右片源比例不同时分别等比包含 |
| 一个工具如何操作 | 实录画面保留关键按钮、输入和操作对象 | 点击、等待和结果有明确因果；可压缩真实长等待并交代，避免用静图暗示交互已发生 |
| 主播给出判断 | 回到全幅真人，留下自然手势或停顿 | 观点讲清后再引入新证据；情绪句可以留在脸上 |

先听触发词，再定入点。提前预告对比对象时交代理由，保留价格、结论等后续信息的原有节奏。一个镜头安排一个主阅读目标。底部字幕、主体与画中画的位置按本镜头调整。

## 纸张与照片分次入场

适用于同一段口播先介绍文件、再提到作者、随后引出另一份资料的镜头。在定稿音轨上标出这三个落点，各自对应一次视线转移。台词先介绍人物时，可以先给照片，再引入文件。

| 口播落点 | 关键帧怎么放 | 观众要看清什么 |
| --- | --- | --- |
| 开始讲第一份文件 | 日期与标题先站稳，纸张从下方滑入展示区，接近落点时减速。用展示区边缘遮住尚未入画的部分 | 纸页的全貌和身份，底部对白与署名清楚可读 |
| 念到作者姓名 | 从姓名起音帧开始，让照片从右侧带轻微倾角滑入，逐渐转平，减速落在纸角，随后停留 | 观众能辨认作者的脸，也能看到他与文件的关系。照片落点避开文件的关键句 |
| 引出下一份资料 | 把已落位的照片与旧纸张编为一组，一起缩小并向侧面让位。必要时把照片略向纸内收，给新文件留出主阅读区 | 新旧资料在同一画面交接，移动全程保住人脸、日期与单位 |

「一天之间」的定稿中，说明书随“毕竟”进入，约 0.56 秒停稳。从纸张起动算起，约 0.8 秒后念到“Alpöge”，照片用约 0.44 秒落到纸角。次日声明入画时，左侧仍能辨认原作者。新片按台词间距、素材尺寸与阅读方向安排时长和来向。用手机大小带声连播整段，再抽查纸张单独停稳、照片入场途中、照片落位以及新旧资料交接的画面。

## 概念动画按词落点

当“失业”“替代”“成本上升”等结果缺少直观对象，且动画能帮助理解时，把它转成一个可辨认的状态变化。先说明对象原本是什么，再在关键词处改变状态，最后给结果留出阅读时间。选能对应台词的工牌、文件、货币或实物；素材本身已清楚表达时保留它的真实动作。

“失业”的一种表达是：在岗工牌入场 → 周围岗位依次退场 → 中央工牌翻面，显示失业状态。工牌阵列表示概念，不给其数量附会失业比例，也不借真实员工照片暗示其已被裁。画面适当标明示意；预测与已经发生的事实在相应口播或材料处区分。

按最终字级时码安排：

- 建立对象：用约 0.2–0.4 秒进入，留出辨认工牌和原状态的时间。
- 语义变化：铺垫词可启动连续退场，重点词起音时开始中央对象翻面或放大，尽量在词尾停稳；不要按整句字幕的起点触发所有动作。
- 多对象退场可错开约 0.04–0.08 秒形成次序。翻面、旋转或下落服务于状态改变，避免无意义持续晃动。
- 结果保持可读，再接真人或证据。图解不因铺满屏幕而挤压字幕；下落对象裁切在素材展示区内，运动途中也不能越过字幕和必要署名。

分镜中记录触发词、动作起止和停稳后的阅读目标。原创建模、绘图或动画按 `purpose: explain` 记录；示意媒体不能作为已发生事件的证据。验收从最终文件连播整句，再看对象入场、退场极值、翻面最窄处和最终状态，确认手机上能读懂前后关系。

## 从整页移到局部

先找真实原图或清晰录屏，确认方向和有效范围。整体阶段优先等比包含完整主体，横图可利用上下留白。局部阶段取真实段落或图表范围，给单位、表头和上下文留边。声明摘句配语义高亮时，旧页可缩小让位；切到新证据后将已读的高亮退出。纸张、真实摄影和品牌标志保留自身颜色。

本技能附带[证据镜头渲染脚本](../scripts/evidence_move.py)。它把静态文件、海报或图表变成一段无声 H.264 素材，先停全图，再平滑推至指定范围，最后停稳。输入框为按 EXIF 方向摆正后原图的像素坐标，依次为左、上、宽、高。按真实输入重新取框。例子假设原图至少 1200×960，参数中的秒数落在当前口播的可用区间内。

```text
python scripts/evidence_move.py page.png detail.mp4 --detail 180 610 900 210 --size 1080 1280 --establish 0.9 --move 0.6 --read 1.5 --fps 25
```

需要 Python、Pillow、可编码 libx264 的 FFmpeg。可用 `--ffmpeg` 指向本机程序。镜头尺寸是画面中留给该素材的区域；插入主工程后另合成真人与字幕。一行很宽的文本放大后仍需看手机实拍大小，必要时另提取短句。观众需要看交互或物理动作时换用实拍动态。

## 局部修订范例

口播讲历史跨度，画面已有年份、题名、年数和倾斜手稿。用户圈出横线时，在标题层定位单独绘制的分隔线，移除该绘制操作，让题名和数字靠空白分层。手稿边缘和后续解释数学概念的坐标线有实际用途。将转场前、画面停稳时和转场后的同帧对照，检查文字、数字、资料边缘以及原声同步。
