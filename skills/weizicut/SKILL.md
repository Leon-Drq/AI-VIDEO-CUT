# weizicut · 薇子姐口播精剪

收到口播文件后，直接从听稿做到可播放的正式 MP4 和同名 SRT。修订时以最新确认的剪辑和对白为底，保留已经通过的内容，另存新版本。默认 9:16、1080×1920、30 fps、真人原声原速。用户指定加速时先试听，音画同时变速并保留音调。参考资料、工程和客户原片保存在本期项目。

## 剪辑顺序

1. 通听原片，核对人名、机构、数值、否定和限定词。用本地转写定位原话；有重录时保留最顺的一次，按一口气的意群去停顿、复述和口误。逐一听剪口前后半句。锁定时间线后，字幕、人物遮罩、口型、动效和声音都用成片时钟。
2. 逐句标记“说到谁、说到什么动作、哪份材料能让观众看见”。建立工作单，记录落词时间、真实主体、素材出处、原始视频入点、要看的细节及退场时刻。先拿到能够说明事情的资料，再决定镜头结构。客户面向中国观众，优先使用能核实的中国团队、国内现场、中文页面及产品实拍；延续客户要求，不用外国人物素材。出镜者以本条口播真人为准。
3. 剪前看用户指定的样片；若原工程和已确认成片可用，抽看开头、主体换位、纸张或照片落定、人物手势、结尾，再回看对应声音。用同一句话比较改动。新题材从其真实对象取材，论文、车载终端和前一条成片的时间点都只是案例。
4. 第一帧让观众看见讲述者和问题。第一个具体名词出现时，给对应的真实对象；提到论文就亮出标题页和署名，纸张随首字展开并配翻纸声。转向产业或另一个主体时，再切其产品或现场，保留简短来源或机构名。观点落在强调词时轻推近。正文在真人大字、满幅现场、资料特写和多对象比较之间随句意切换。详细镜头、材质和声音见[剪辑台手册](references/editing.md)。
5. 使用本技能的[本地制作流程](references/production.md)锁对白、抠像、编排镜头、混音和渲染。也可以沿用现成工程，以同样的分镜和验收条件出片。内容判断、素材搜集、字幕校对和配声都是执行者的工作；只给原片时不要求用户填写工程表。
6. 做三轮有针对性的对照：① 对白与证据是否对应；② 手机尺寸下的焦点、贴纸、动效、边缘和素材密度；③ 完整播放最终编码，听音效落点，核对口型、字幕和片尾。发现问题，修复后重看涉及段落和相邻剪口。用效果和可读性决定是否通过；仅有导出成功或场景数达标不足以交付。
7. 在本期成片目录交付可点击的 MP4 和 SRT。需要看入场、对比迭代时可另给开头短预览。客户原片、肖像、录音、参考样片和成片留在本机，公开技能归档只包含通用方法与脚本。
