# 镜头、材质与声音

## 前三秒与后续节奏

开头让真人和第一个叙事对象同屏，脸在第一帧可辨，证据占够面积。把题目提炼成观众当下能回答或想追问的一句话；真人段可用人物背后白色大字，只保留一次主标题。可在关键词起音时用约 0.30 秒推至 1.04–1.07 倍。标题、字幕、来源行各承担一种信息；删掉泛化小标签、装饰线和网址，网页原始地址只进本地来源表。

样片的第一句提到论文，于是原页先展开，问到“怎样能带动一个行业”才移到另一家公司的车载终端。纸张与终端曾属于不同机构。分别标明来源，两者之间用提问过渡，避免将它们剪成同一团队的上下游成果。新片如果讲门店、软件或一组数据，首个证据应换成真实门店、操作画面或原始数据。

正文随名词或动词更新画面。讲同一件事，可以沿用同一个镜头，从全貌进到原句、手势、操作结果；列举多个主体，先让每个各自占主画面，再将已出现的对象缩至侧边，最后合拢比较。一次演示从案例切到比较版面时用同一段解码时间和动作，缩放期间继续播放。讲结论或个人判断，适时让真人回满屏；结尾优先回扣开场问题。连续几个实体只有口播人像、同一张图来回漂移，或截屏半屏且其余大块空黑，都应重排。单句信息密度高时给足阅读时间。

## 图层与材质

| 画面 | 操作要点 |
| --- | --- |
| 资料舞台 | 深石墨底，保留大面积暗部。将低对比线框球放到上侧边缘，下侧做缓慢起伏的网格和少量沿线光点。按成片时间连续运动。正文、脸和原始照片保持自然对比；整幅实拍可直接铺满。 |
| 真人贴纸 | 从本条视频逐帧抠像，剪口重置时序遮罩。保留柔和发丝，用主要外轮廓生成暖白模切边，1080 宽画面约 8–14 px，配短窄软影。原始画框截住手臂时避免在截面包出一条白直线。入场约 0.3 秒，几像素落位、一次轻回弹。 |
| 真人与资料同屏 | 第一屏人物可在右下；避开证据和字幕。正文资料占主位时，真人移至右上同步圆窗，直径可从画宽的五分之一开始，暖白圈约 6–8 px。逐段检查头顶、嘴型和动作，必要时移到另一侧；返回真人段收起小窗。 |
| 论文与原帖 | 取原始首页、署名或发布者，先给整体，再沿阅读顺序放大真实原句。纸页从折线展开，约 0.3–0.45 秒落稳，留小折角、窄纸边、接触阴影。引用节录要标成节录。 |
| 现场照片、肖像和产品 | 照片可用细相纸白边，轻微倾斜后停稳。提到具体人时引入真肖像，提到其一次发言再给能核对的原帖。产品和网站使用真实界面与原始 Logo；界面宜正放细边，可轻微做透视后回正，给观众读图时间。 |
| 字幕与配色 | 暖白粗黑体或中文无衬线；重要对象、动词或数字每句选一个用姜黄 #FCC96E。优先实切短句，一到两行，留足手机底部操作区。粗大背景字可适度被人遮挡，但要读得出；避免叠加第二套标题。 |

## 混音与三轮回查

- **声音先跟动作。** 纸页刚掀起叠翻纸声，相片滑入用短摩擦声，屏幕切换可用克制的短扫声，比较组落稳才给轻触声。音效的有声起点对准可见动作，不能只对齐有前导静音的文件头。语气收束或多层连续进入时，有意留下安静片段。保留真人音色；新一期根据语音和素材试听决定听感，不强制铺音乐。
- **取舍和证据。** 一边听一边按实体清点画面，特别检查并列清单的最后一项、前后机构归属、示范视频动作的连续性、现场是否属于所说主体。所有关键证据在关键词处出现、够大，并在下一论点前退让。核实不到原帖时可用可核验的原文节录或产品实物；中性说明镜头需明确其用途。
- **手机画面。** 对照参考的同类句子查看首帧、入场中点、落定和退场，抽看手势最大的帧；检查人像边缘闪烁、肩膀被切、半截主图、空场及文字相互压住。缩到约 360 像素宽仍要读得出主标题和关键信息。
- **声音与导出。** 整片从头到尾听一遍，听每个剪口、纸声与句首辅音，小音量再听人声。可从约 −14 至 −16 LUFS 和真峰值不高于 −1 dBTP 起调。检查口型、字幕、进出点、尾字完整、全片解码、黑帧与意外长静音。计量异常应回到对应段实际判断。你应当交付修正后的正式文件。
