# 可调整的视觉起点

以下是 1080×1920 竖屏起点，服从新素材构图；横屏重新排版。

| 元素 | 起点 | 调整依据 |
|---|---|---|
| 素材展示底色 | 暖白 #F1EFE6 与深色 #11171B | 随语义段落组织明暗变化，实景保持自然；具体方法见 [hook-and-polish.md](hook-and-polish.md) |
| 素材展示主文字 | 深色场景用米白 #F5F1E7，暖白场景用炭黑 #11171B | 与真人主标题分开设置，保持与案例细节的对比 |
| 强调/路径 | 姜黄：深色/真人上 #D3AD55，暖白上 #966A24 | 自制标签与字幕关键词统一；保留真实素材、图表和品牌自己的颜色 |
| 对比项 | 暖橙 #E8A574 | 表达旧状态或对比数字 |
| 真人开场/观点主标题 | 白色粗重无衬线，正常字宽；1080 竖屏短标题可从 140–244 px 试排 | 无底框，人物自然挡字；依据实际字形、字数、头顶空间与动作调整，不套固定坐标 |
| 素材章节标题 | 96–120 px，清晰粗体、正常字宽 | 按画面明暗选择字色；先缩短/换行，不挤窄字体 |
| 标题副行 | 44–56 px，与主行独立定位 | 行间留约 18–30 px 视觉空隙；避免挤成一个小角标 |
| B-roll 对象标题 | 88–104 px；长地名可用 80–96 px | 给人像小窗留位，按真实字体测量；标题不碰窗框 |
| 圆形人像 | 直径约 280 px，边框 3–4 px | 一般右上，避开素材主体与标签 |
| 双语字幕 | 中文约 64 px；英文约 39 px | 字体实测宽度和手机可读性优先 |
| 字幕分区 | 单语先按案例高度与平台底部 UI 排；双语分两区实测 | 不沿用旧片固定 y 坐标；需放大案例时先重排字幕与标题，不能压扁案例 |
| 主要案例 | 1080 竖屏约 1000–1024 px 宽起排，等比决定高度 | 完整包含，先整体后细节；见 [完整取景](full-frame-materials.md) |
| 关键文字留白 | 两侧约 6% 画宽起排 | 按平台 UI 安全区域调整；案例外边可更宽，轴、按钮和说明仍需安全可读 |

画面语法可用“真人提问→对象实景→关系图解→真人感受”，不是每段必须照走。

强调色用于自制覆盖层，不做全片色相替换。姜黄在亮背景上对比不足时用较深版本或改位置；不要把素材中的绿色鞋、品牌色和数据系列一起改黄。真人背景保持自然，不新增虚化、马赛克或生成替换。

## 标题字体与对比

先决定该镜头是否需要标题。清楚的肖像或实物已经表达名词时，优先让图成为主体；以下字号只用于确有必要的标题，不要求每段摆姓名大字。真实照片、人物肖像与实物分层的选择和动作见 [image-led-motion.md](image-led-motion.md)。

开场/章节/姓名牌与字幕分开设置字体、字号、字距、行距、描边和阴影，尤其 ASS 不应继承 CN 字幕样式中的粗描边。真人主标题默认使用白色、粗重无衬线字体，如 Noto Sans SC 900、思源黑体 Heavy 或合适的本机粗黑体。保持正常字宽，不压扁、不拉窄；通过字重、大小和留白建立力度，阴影仅作克制的分离。

真人主标题不加黑框、圆角卡片、横条或半透明底板，不用厚描边补对比。浅色或复杂背景优先换排字位置，必要时只对人物后方背景作自然、轻微的明暗调整，不压暗肤色或盖成一块可见的补丁。素材展示仍可按暖白/深色场景选字色；此偏好不取消对白字幕的必要可读性处理，也不删除真实产品界面本身的面板。

主标题通常只承担当前观点的少量关键词，不复制整句字幕。按字体实际字形边界测量宽度与顶线，先精简或换行再调整字号。先看输出原尺寸，再看约 360 px 宽手机预览；主副行层次明确，遮挡之后仍能一眼认出关键词。不要把某条视频的 244 px、坐标或字距设成全部视频的固定值。

## 人物自然遮挡标题

适用于有清楚真人前景的开场、章节与关键观点镜头；资料全屏或小窗讲解按信息层级另排，不为巨字破坏案例展示。

1. 先确定对白剪口与变速，人物、标题和连续 alpha 遮罩共用最终帧时间轴。已有抠像缓存可复用，但必须对应同一原片帧、裁切与缩放；镜头切换时重置时序状态。
2. 分层顺序为原背景或局部调色后的底图 → 白色大标题与轻阴影 → 用人物 alpha 恢复原始人物像素 → 其他必要提示 → 最后对白字幕。可使用现有连续视频抠像方法，不强制迁移工程；保持原脸、帽子、衣服、手势与肤色，不用生成式替换人物。
3. 按头部与手势的实际运动范围，安排一部分文字处于人物后方。头发、帽沿、肩膀、手势自然遮住相应字形，文字不能漏到脸、嘴或衣服上。保留足够笔画以识别关键词，不能为制造重叠而遮住整词或裁掉人脸。
4. 文字只是悬在头顶、完全没有重叠时，不声称已实现人物遮挡。空间不合适或边缘不稳时，先调整位置与重叠量；仍无法自然呈现则改成旁侧/上方无底框大字，并在检查记录中说明。不要退回黑卡片，不用固定椭圆或矩形蒙版假装精细抠像。

标题入出可用短促、平滑的位移或透明度变化，跟随语义而非持续弹跳。检查最终编码文件的入场、中段、转头/抬手极值和退场，并播放动作片段：发丝与帽沿无明显光晕，轮廓不闪烁，手势不穿字，没有硬接缝，底部字幕不被人物层盖住。静态截图只能证明该帧，不能替代连续遮挡检查。

## B-roll 密度与对象覆盖

本 skill 的默认偏好是配图较丰富、文字克制。对信息型短访谈，可从 **45–60% 的资料/图解主导时长**开始规划，用户明确要求密集时可尝试 **50–65%**。这是创作起点，不是凑比例的门槛：笑容、迟疑、关键回答和互动保留真人；素材不足时不能拿无关图补时长。

- 逐句找对象，不只找结尾的风景。例如说到州名，可在准确发音处显示当地实景或数据地图；说专业，可用相关机构场景作为学科说明，但不暗示受访者就读/任职于该机构。
- 地域图必须标清代表范围：州内某城市景色只是州的地域资料，不能直接写成嘉宾家乡城市。历史街景不是童年旧照；社团图标是选择示意，不是现场社团名单。
- 有新信息时，通常每 3–6 秒考虑一次真人/实景/图解/构图变化；发现 8–12 秒连续真人且经过多个可视化对象，应重新检查是否漏配。没有新信息或需要情绪停留时不要强切。
- 单段实景一般 2–5 秒；地点出现很短时，可延续到关联句而非闪一帧。若紧接下一个实体，要安排分屏或切换，不能为最低时长提前泄露下一个对象。
- 信息卡以图为主。地图定位、物件、真实照片与简短标签优先，不用再写一段解说。超过 2.5 秒的信息卡有多个论点时依语义分状态；完整案例需要阅读停留时记录 `hold_reason`，不为通过检查硬加状态。照片可轻微推近，但不能裁掉主体边缘。
- 同一段配画面内可有“地图定位→当地实景”的变化，记录各层的开始时刻；前后呼应可重复，但说明用途。加入大人像小窗后，该区间仍算一次 B-roll，不能重复计数。

交付前汇总：可视化对象清单、已配素材及未配理由、B-roll 时间并集占比、最长连续真人段及保留原因。每个具体地名/专有名词要做一次遗漏检查，覆盖比例达标不能掩盖“明明说到对象却没有对应画面”的问题。

横向山景可用大照片面板与柔和背景，避免竖裁切掉山顶；竖向房间图可全屏铺开。平缓推近约 2–5% 通常足够，不用不停缩放假装丰富。

标题是观点，字幕是对话，来源是归属；避免三个位置重复同一句话。具体数字先听到/读到再出现，不用装饰性大字提前泄露回答。

检测器的脸框可能不含头发，下巴与发顶需单独确认。按完整头部范围计算取景，再检查圆形遮罩后的余量；具体方法见 [portrait-framing.md](portrait-framing.md)。多人物按角色稳定选人，适度平滑跟踪；镜头切换时重置，不从一个人缓慢漂移到另一个人。
