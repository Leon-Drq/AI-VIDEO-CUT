# SoloLoop视觉规范

默认1080×1440、3:4、30fps；底片→真实B-roll→大字/身份/卡片→题头→章节进度→Logo→字幕。改画幅须重排；横屏保护主体，不拉伸，不强裁掉关键人物。

| 元素 | 基准 |
| --- | --- |
| 颜色 | 橙#F59A31、白#FFFFFF；Logo原色 |
| 黑体大字 | Noto Sans SC 900，常110–190px |
| 身份大字 | Noto Serif SC 500，短英文/数字可250–310px |
| 身份说明 | Serif 500/600，80–100px |
| 字幕 | Serif 600，58px，长句48–54px或拆分 |
| 主标题 | 左58–70px，常见y700–1020 |
| 身份区 | 左上真实留白，约x58/y157，说明y467；避脸和麦克风 |
| 数字卡 | rgba(35,39,42,176)，圆角22px，数字约130px |
| 递进卡 | 88–96px，常见y676/830 |
| 字幕区 | 墨迹顶y1058，左右约60px，最多两行 |
| 章节条 | 顶部57px灰半透明，当前白粗，其余灰 |
| 进度 | 下缘3–4px，随全片时间前进 |
| 小题头 | y82，29–31px，止于Logo左边 |
| Logo | 原PNG等比宽250px，右40px、顶77px，必要时轻阴影 |

Windows优先Noto SC可变字体。Linux可用Noto/Source Han CJK字体集合，记录实际替代字重并检查字形；不要无中文的Arial回退。

开场用橙核心词+白问题；现场定位2–3行厚黑体；身份用巨大衬线词+中文说明；年份数字卡；方法按原话递进；结尾白+橙简短总结，不替嘉宾背书。字幕白色、少量橙高亮，浅灰描边与约(3,4)px、模糊2–3px柔影，避免厚黑边/粗黑斜体。

字符交错25–55ms，单组150–250ms，ease-out小位移与轻弹。问题可200–250ms散字退出，其他短淡出；卡片轻移淡入。首屏立即可读，不留半秒空白。不长时间模糊、磨皮、假景深或堆转场。

按人物框避让，不机械套坐标。测长姓名/英文宽度，缩小或换行。Logo避章节，题头避Logo，卡片避字幕。检查360px手机预览。白字优先轻影/文字面板，不给人物叠灰蒙层。保持原版Logo字形/配色/比例，不生成近似标识冒充原图。
