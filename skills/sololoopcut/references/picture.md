# 色彩与清晰度

逐条读像素格式、传递函数、原色、矩阵、范围、旋转和Dolby Vision信息，同场也不能统一假设。

| 输入 | 处理 |
| --- | --- |
| SDR709 | 不套HDR映射，只做必要曝光/白平衡/镜头匹配 |
| HLG/BT2020 | 浮点线性解码、色域转换、映射709 SDR |
| PQ | 正确PQ解码，从MaxCLL/母版亮度核实峰值，不照搬HLG |
| Dolby Vision | 优先正确工具；采用HLG兼容基层时记录未用RPU |
| 元数据缺失 | 抽帧比较合理解释，不无依据贴HLG |

本次HLG起点：原生crop→zscale到1080×1440、linear/npl100→gbrpf32le→primaries709→hable/desat0/peak10→zscale709/tv/error_diffusion→yuv444p10le。peak10对应本次线性峰值，不是所有HDR万能值。

看肤色、白衬衫、彩色麦克风、投影和窗户。不要无检查desat1再降饱和，把橙色漂白。本次mild grade为saturation0.95/gamma1.02/unsharp3×3 amount0.25，新片按实际光线调整，SDR不强加。部分eq/unsharp内部可能8bit，无损容器不等于全链10bit；精度敏感时用高位深等价滤镜并验证。

保留真实红蓝投影/暖灯，不把脸去成灰白，也不全场推橙。无色卡不声称严格色度还原。比较无图形底片、实际编码成片和旧版，分清tonemap、缩放、压缩、矩阵问题。输出明确709 limited标签。

4K原生裁切后Lanczos缩小。1080p人脸不为特效再次放大。不全画面模糊、磨皮、强降噪或假景深。轻锐化增强已有边缘，无法恢复失焦、运动糊和过曝；不生成式补画嘉宾脸、表情和口型。身份字蒙层不覆盖脸。

原片→原生裁切/调色→FFV1无损段落→图文/Logo/字幕→一次H264 CRF16。禁止多代CRF归一化/分段/成片有损链。修复从原片或干净无损底片开始。
