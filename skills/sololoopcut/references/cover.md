# SoloLoop 中文封面

用户要求活动视频或小红书封面时使用本规范。默认采用客户确认的斜体大标题；用户当次明确要求优先。只修改封面时，保留已确认的视频剪辑、音轨和其他封面元素。

## 默认样式

| 项目 | 执行规则 |
| --- | --- |
| 画幅 | 3:4竖版，默认1080×1440或等比例更高分辨率 |
| 标题字体 | 优设标题黑 / YouSheBiaoTiHei，使用其原生向右倾斜字形，约8°；不默认改成直体 |
| 标题颜色 | 纯白 #FFFFFF，实心扁平填色 |
| 标题效果 | 不加立体、挤出、浮雕、渐变、阴影或描边；不使用奶油白或橙色主标题 |
| 标题语言 | 根据当期视频内容写中文主题；可保留AI等必要缩写，不加AI MEETUP、ROOMTOUR等英文装饰口号 |
| 主体 | 使用当期视频中清晰、有表情的真实嘉宾，突出面部与现场感 |
| 品牌 | 右上角使用 assets/SoloLoop-logo-original.png 原图，等比缩放并保留原配色 |
| 排版 | 上方短主题，下方1–2行观点或问题；大字醒目，人物位于中间，脸部无遮挡 |

## 人物与画面

从原视频提取清晰、高分辨率的真实画面，先按画质规范正确处理HDR/SDR。选择自然微笑、交流或发言表情，避开闭眼、运动模糊和口型失真的帧。用户要求女性嘉宾时，从实际素材中选择，不生成陌生模特替换。

保留本人五官、年龄观感、发型、服装、坐姿及话筒。允许合理裁切和轻微曝光、白平衡调整；不为增强吸引力而重画脸、改变肤色或制造不存在的现场。保持自然暖色与皮肤细节，不默认套浓橙滤镜、磨皮或假景深。

修改字体、斜度或颜色时复用已确认的照片与构图，避免连续重生成导致人脸和背景变化。保留原始素材及旧版封面。

## 字体与版式执行

1. 优先使用实际优设标题黑字体文件，检查字体内部名称及最终渲染字形。字体自带倾斜时不要再次斜切，避免双倍倾斜；不用给整张画布旋转来代替字形倾斜。
2. 从合法本机字体或发行方取得字体，发行页为 https://www.uisdc.com/uisdc-first-free-font 。公共技能不默认捆绑字体文件。无法取得该字体时，明确说明替代字体；生成式字形近似只标为风格预览，不冒充使用了真实字体文件。
3. 按新素材提炼主题，保留观点的疑问、限定或否定。不要每期照搬旧片标题，不用封面替嘉宾编造结论。
4. 在约1080px宽的封面中，左右及上下先留约40px安全边距。标题可以大，但斜体最右侧笔画、问号和Logo必须完整入画；按字形实际边界测量，不只测文字框。
5. 将上方短主题与下方核心问题组合成一个完整中文标题。可让头发轻微压住上方大字边缘，但不能妨碍识别；避开脸、手与关键话筒区域。
6. Logo放在右上角的真实留白处，避开标题和人脸。保留SoloLoop品牌字标及其中文说明，不生成式重画近似标识。
7. 白字与背景对比不足时，优先调整文字位置、大小或裁切。保持扁平白字，不添加投影、文字底板、贴纸或整个人物灰蒙层。

例如素材确实讨论AI转型时，可排为上方「AI时代」、下方「转型 / 更容易？」。这只是排版示例，不是新素材的固定标题。默认标题斜体、照片和Logo保持正常方向；片内字幕、身份字与橙白大字不随封面规则改变。

## 交付检查

- 检查导出图的文字是纯白扁平斜体，中文、标点无错字、缺笔或裁切，没有额外英文口号。
- 检查约360px宽手机预览：一眼读出主题，面部清晰，标题与Logo不相撞。
- 对照源帧确认嘉宾身份、面部及现场细节，对照原PNG确认Logo字形、配色和比例。
- 按环境要求保存并交付封面；生成图按环境的自动保存方式交付。不要因封面更新而重剪或重编码视频，不擅自发布到平台。
- 在公开技能中保存本规范，不默认上传当期原视频、嘉宾肖像或成片。
