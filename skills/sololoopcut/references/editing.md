# 素材与语义剪辑

先实际读取素材，探测时长、旋转、流和显示尺寸；把对标、旧成片和工程输出分开。只在用户提供范围内有选择地递归。查看每条原片开中尾、人物和场景变化。转写用于定位，画面用于判断机位、表情和遮挡，不凭衣着相似编身份。

| 段落 | 常见长度 | 剪法 |
| --- | --- | --- |
| 真实抓人观点 | 前3–5秒 | 立场或反差，首屏关键词可读，人物可见 |
| 活动定位 | 2–4秒 | 2–3个真实现场切面，单镜常0.8–1.5秒 |
| 人物经历 | 8–14秒 | 有依据的职业、经历、变化，用身份字/年份卡 |
| 具体方法 | 10–18秒 | 行动、因果和学习路径，逐项揭示 |
| 启发收尾 | 6–12秒 | 自然反应与交流感，简短总结落点 |

上表是语法，不是固定EDL。没有内容就缩短，单人、横屏、多人各自判断。删赘词、重复起句、明显失误、无意义停顿；保留呼吸、情绪和“我觉得/可能/比较/不/不是”等改变含义的词。按完整意群切，检查切点前后约0.15秒，避免半字、吞音和截尾。默认原速，不用固定加速替代选择。

以硬切为主，用真实B-roll或小幅景别变化隐藏跳切。4K可1.02–1.10倍轻微重构图；1080p人脸优先原生尺寸。J/L cut须避免看起来是另一人在说话。不用定格冒充动作，不用无关生成场景冒充活动证据。

保留完整句尾并避开递麦、路过、遮脸和突然离焦。收尾留约0.3–0.6秒干净表情或真实活动场景，不为凑长度保留脏帧。

大字为精炼提取或明确编辑性话题，数字、单位、年份、职务有来源。没有验证姓名就用职业/主题。收音差宁可不用逐字台词，可保留已核实话题和画面。迁移对标视觉语法，不迁移履历、观点或音轨。新对标须实际查看。
