# 渲染与交付

建立独立工程，原片不移动覆盖，旧版版本化。保存source-inventory.json、transcripts.json、edit.json、SRT、混音、无损段落、正式MP4和QA。扫描排除对标/工程/输出，避免递归入库。

验证源路径、入出点、整数帧、时长、字幕/图形/章节边界、字宽和Logo安全区。看各源调色样张，尤其HDR肤色/高光和彩色物体，SDR不重复映射。

看实际编码的全部镜头类别、文字阶段、所有切点前/当/后和首尾三秒；看脸、麦克风、字形、数字、英文、卡片递进、Logo，做360px预览。完整解码、尺寸/帧数/帧率/时长/色彩/音频流必须正确。黑帧停帧扫描仅提示候选，要逐个判定。

测最终LUFS/dBTP，听吞音爆音、底噪变化、BGM避让和尾音；没听审能力须记录限制，不声称人工验收。视觉修订复制音轨要核包hash。区分技术通过、待判断候选和未做检查，先解决实质问题。没新改动不反复测试。

默认H264 high / yuv420p / CRF16 / 1080×1440 /30fps /709tv /AAC48k stereo /faststart。回复给正式MP4链接和本地绝对路径，可附有用对比；方案/预览不能代替成片，不擅自加封面、文案或发布。
