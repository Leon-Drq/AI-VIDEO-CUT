# 冷科长式 B-roll 精剪

交付一条可以直接观看的正式 MP4：人物负责表达，素材帮助看懂具体对象，图解解释关系，字幕承担听读。借鉴参考的剪辑原则，不复制无关素材或保证流量。

## 默认与输入

- 原片或已有成片即可开始。优先读取项目现有 EDL、干净画面、字幕、词级转录和参考分析。
- 已有成片默认保留时长、叙事、原声和字幕语言，只增补视觉；原片先精剪自然对白，再按新时间轴制作 B-roll。
- 素材升级沿用已确认的剪口、速度和字幕时码；例如用户已选 1.2 倍则保留，不把该速度设成所有视频的默认值。
- 默认加强成片前 3 秒、移除画面网址并精修素材构图；已有成片先做视觉升级，不为钩子擅改叙事或提前展示尚未讲到的数据。执行前读 [references/hook-and-polish.md](references/hook-and-polish.md)，用户当次明确要求优先。
- 真人开场、章节或观点镜头需要主标题时，默认“白色粗重无衬线大字＋人物自然遮挡”：无标题底框，原始人物在文字前方。具体字体、分层与边缘验收见 [references/visual-system.md](references/visual-system.md)。这是本用户的标题偏好，不要求所有 B-roll 或每个镜头都加巨字。
- 沿用当前比例与清晰度要求。竖屏无特别要求可用 1080×1920；源片只有 720p 时记录上采样，不声称细节是原生 1080p。帧率按素材与项目确定。
- 本 skill 默认自检后直接交付正式 MP4，不设置预览审批门槛。关键输入缺失时先推进独立工作，再精简询问。
- 不因历史英文版任务自动进行英文配音、克隆声音或口型生成；这些须来自当前任务范围。
- 保留原片和旧成片，使用版本目录或新文件名。剪辑授权不等于公开发布授权。

## 1. 看素材，确定表达

探测流、时长、帧率、旋转、分辨率和音轨。看首尾、构图变化及关键回答，找出必须留在真人上的表情和互动。写简短剪辑意图：核心信息、钩子、人物段与解释段；用户要求明确时直接落实。

有参考视频时提炼节奏、字体、色彩、B-roll 逻辑与画中画比例。没有可访问参考时使用本 skill 的抽象方法，说明依据，不声称看过未读取的视频。视觉起点见 [references/visual-system.md](references/visual-system.md)。

图先解释对象，文字只补关键事实。人物优先可识别的真实肖像，群体优先自然照片，产品优先真实资料；不以姓名大字、简笔人形或不知所指的科幻装置替代。用户要求素材更精美、实物动效或多用图时，制作前读 [references/image-led-motion.md](references/image-led-motion.md)，按台词建立对象、关系和动作，避免只换配色。

## 2. 建语义时间轴

原片精剪时保留核心结论与限定条件，删除重复、空泛铺垫和无证据的热度宣传；不为了固定时长删掉论据或改变原意。开头优先使用原声中最明确的事实或问题，不捏造冲突。

先完成或复用干净对白剪辑。输入有硬字幕时优先找无字幕中间文件；找不到就沿用硬字幕并为新增内容留位，不重复烧录或盲目裁掉下巴、手势。

将配画面的词句映射到最终时间轴，记录入出点、`spoken_anchor`、`asset_key`、用途、画面类型、信息状态及来源。

先列出可视化对象清单：地名、机构、专业/职业、运动/产品、时间经历与对比。每个明确对象决定配实景、定位地图、说明图解，或因保留反应/缺少可靠素材而留真人；避免只给后半段旅行地点配图，却漏掉前半段籍贯等明确对象。按 [references/visual-system.md](references/visual-system.md) 的密度起点规划，并在交付检查中记录实际覆盖时长与遗漏理由。

- 地名、产品名、数字在说到时出现。默认最多提前 0.10 秒；需要提前建立理解时记录具体理由。按实际帧率量化入点。
- 图解解释路线、时间、步骤、比较；生成画面只能作说明，不能代替事实证据。
- 超过 2.5 秒的全屏信息卡安排至少两个有意义的信息状态，按叙述顺序揭示。真人或风景镜头不因此强制塞文字。
- 同一素材默认只用一次；呼应性重复注明用途。不要为覆盖率遮掉关键人物反应。
- 保留“希望”“可能”“两个多小时”等限定，不能改成已实现承诺或精确导航时间。

使用 [scripts/init_project.py](scripts/init_project.py) 建版本目录。字段和验证见 [references/project-format.md](references/project-format.md)。

## 3. 获取真实对象素材

优先顺序：用户原始素材 → 对象自己的公开账号/官网 → 可核验资料 → 原创说明图解。

科技、产品与数据题材核对参数单位、总量/激活量、比较口径、报告发布日期和排名所属评测。旧视频保留录制时期语境；当前资料不能悄悄改写历史陈述。资料支持不了的句子应保留限定、删去可独立删除的夸张段，或明确提示待核实，不生成假截图佐证。来源记录 URL、访问日期、支持的具体结论及成片使用位置。

完整 URL 保存在项目 `SOURCES.md` 或素材清单，不烧进画面。逐项处理来源角标、网页地址栏、页面正文域名、二维码和收尾链接；可保留必要的来源名称、作者、日期和许可文字。不能只删除自己添加的角标，漏掉截图或录屏内的地址。处理顺序与署名取舍见 [references/hook-and-polish.md](references/hook-and-polish.md)。

用户打开网页并要求获取素材时，按 [references/source-acquisition.md](references/source-acquisition.md) 实际下载、看图、保存来源并剪入成片，不停在“可以获取”。

建筑、房间、产品必须确属对象。地域风景不能冒充某家店的窗景；拿到自有账号实景后优先替换泛素材。照片可平移推近，但不把照片说成拍摄视频。

## 4. 合成人物、素材与字幕

根据意义切换真人、B-roll、图解和画中画。默认硬切，推近强调关键观点，不做固定周期缩放。

素材展示默认结合暖白与深色两个场景，按案例、工具、证据等语义安排明暗变化；真实拍摄环境保持自然。优先“真实案例整体 → 可解释的局部细节”，让分层、阴影与留白服务于对象关系，具体构图和验收见 [references/hook-and-polish.md](references/hook-and-polish.md)。

- 1080 竖屏圆形画中画从约 280 px（画宽 26%）开始，按手机尺寸可读性调整。
- 画中画取景必须包含完整头发、下巴与适量肩膀；圆形遮罩还会裁掉方框四角，不能只看未遮罩的人脸截图。制作前读 [references/portrait-framing.md](references/portrait-framing.md)，在成片尺寸上复核。双人素材选择说话者或明确的反应镜头。出框、遮挡时改构图，不随意跳脸。
- 实景保留来源；图解必要时标“口述示意”“愿景”，不塞装饰性假数据。
- 主标题与正文字幕使用独立样式。真人主标题用白色、粗重无衬线、正常字宽的大字，不加黑框、圆角底板或横条，也不沿用字幕厚描边。按“原背景 → 标题 → 连续人物 alpha 恢复原人物 → 字幕”合成，让头发、帽子与手势自然挡住字；不能用静态人像或矩形遮罩冒充连续遮挡。位置与大小按新素材重新确定，完整规则见视觉规范。
- 已被肖像、产品或场景清楚表达的对象，不再叠同义大标题；首次辨认困难时补短身份标签。数字、单位、比较口径与限定仍保留，口播字幕不因“多用图”而删词。
- 中文字幕短句分段、少量关键词变色；英文独立分区。按实际字体测量每一行，不用中文字符数检查英文。
- 字幕在全部视觉层之后合成。中英同时显示是正常排版，只检查各自轨道内部的无意重叠。
- 已有成片仅改画面时优先复制原音轨；原片经过删段必须同步剪音频。只有实际听感收益时加轻音乐或音效，不能盖住对白；声音跟随信息揭示，不给每次切镜都加转场声。

沿用可用的 FFmpeg/Pillow、Remotion 或 HyperFrames 工程，不为本 skill 强制迁移技术栈、安装推理环境或使用付费服务。本 skill 不要求并行子代理。实现易错点见 [references/render-and-qa.md](references/render-and-qa.md)。

## 5. 检查与交付

检查语义时间轴、完整解码、流、时长、黑屏/低运动/异常静音及响度。查看最终文件首尾、关键人物、每个设计转场前后及所有候选异常。

单独检查前 3 秒的信息建立与动作过程、全片网址残留、暖白/深色切换和案例放大后的可读性。检查项目文本之外，还要看实际输出帧中的网址；在报告中记录已查范围，不能以搜索不到字符串代替画面复核。

复核对象清单与 B-roll 密度：覆盖率按资料/图解主导画面的时间区间并集计算；普通字幕、姓名条、重复缩放不算新增 B-roll。明确地名/对象遗漏时给出叙事或素材理由。标题在约 360 px 宽预览中仍应一眼可读，不能以技术行宽检查代替视觉判断。

真人标题检查无底框、粗白无衬线与真实前后遮挡；查看标题入场、中段、转头/抬手极值和退场，检查脸上漏字、发丝/帽沿光晕、手势穿字及遮挡后关键词可读性。只有画面实际发生前后重叠才称为“人物遮挡”；抠像不稳时改位置或减少重叠，保留无底框样式。

实物动效检查入场、最密集阶段、转场和退场：重要人脸、数字与单位始终可见，旧状态标签及时退出。对照参考的主体占比、叠层和动作节奏，检查拿掉装饰性标题后是否仍能理解配图；具体判定见 [references/image-led-motion.md](references/image-led-motion.md)。

照片、静态图解可能触发低运动检测；检查实际帧和真人画中画后记录判断，不能直接称为卡顿，也不能一概忽略。音轨校验不能冒充人工听感评审，只报告实际检查。

交付正式 MP4，简短说明新增内容、原声与字幕状态，并用绝对路径展示视频。项目内保留来源及检查报告。

## 调用示例

- `$lengke-broll 给这段访谈加真实素材和图解，保留原声及双语字幕，直接交付 MP4。`
- `$lengke-broll 按上次冷科长的方法剪这个视频，素材从我打开的品牌账号获取。`
- `$lengke-broll 升级这版素材，人物用真人头像，金融价值段用真实钞票分层展开，多用图替代大字，保留现有语速和字幕。`
- `$lengke-broll 保留现有精剪和原声，加强前3秒，移除所有画面网址，用暖白与深色展示真实案例，优化细节放大、叠层和阴影。`

需要具体案例时读 [references/eddie-example.md](references/eddie-example.md)，不要把其地点、素材和时码当作新视频默认值。

科技口播从原片精剪到成片的实例见 [references/kimi-example.md](references/kimi-example.md)：包含对白取舍、资料图解、短句字幕与本次小窗修正。该实例的数字、时码、配色和裁切坐标均不是新视频默认值。
