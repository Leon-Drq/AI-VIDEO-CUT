# 真实素材与分层动效

适用于“素材太粗糙”“多用图片替代文字”和冷科长式实物合成。这里提炼人物肖像、儿童照片和钞票动效的改进方法；不把某一期的人物、金额、配色、时码或素材网址固定成模板。

## 先决定画面能解释什么

每段用一句话写清：说到哪个对象 → 观众要理解什么关系 → 哪个动作使关系可见。把对象图、语义锚点、动作阶段、保留文字、遮挡区记在项目分镜中，仍按现有时间轴格式制作。

需要对照参考继续优化时，先用 [semantic-shot-design.md](semantic-shot-design.md) 拆解连续的信息状态，决定旧对象如何让位、新对象何时加入，再选择下面的动作。全屏与动画是表现手段，不替代证据和关系的推进。

| 台词对象/关系 | 优先画面 | 需要保留的文字 | 常见误用 |
| --- | --- | --- | --- |
| 具体人物发言或行动 | 可核验的真人头像、半身照或原始画面 | 必要身份、出处；完整口播字幕 | 姓名巨字重复头像；错误人物或生成肖像冒充真人 |
| 一名孩子到许多孩子 | 自然儿童照片：单人局部 → 同场景宽景或少量群体叠层 | 确有依据的数量；泛素材标“情境素材” | 廉价小人网格；把模特说成实际受赠者 |
| 公司、产品或技术 | 真实产品、界面、官方资料；必要时再用关系图解 | 名称辨识、关键参数或来源 | 泛用发光机器、无关机器人充当具体技术 |
| 股份价值、财富规模、分配 | 先明确股份/公司对象，再用纸币实拍或照片表现价值与分配 | 股份数、币种、估值/估算限定、关键金额 | 用撒钱暗示已经现金到账；美元图配人民币数字却不说明 |
| 步骤、因果或精确比较 | 实物对象配少量关系线、图表或必要标签 | 关系词、刻度、单位 | 为了“少文字”删掉观众无法从图片读出的因果 |

画像替代的是冗余姓名标题，不是字幕。首次出现且不易辨认的人物可加小身份标签。照片不能证明人物的国籍、身份、受益或背书；资料年份、示意性质和来源按实际标注。素材来源与许可记录见 [source-acquisition.md](source-acquisition.md)。

## 素材质感先于动画

- 真正打开原图检查清晰度、表情、裁切和背景。先保证手机画面中能一眼认出主体，再添加动作；低清图放大、僵硬人形和整齐方框不会因多加转场而精美。
- 头像选择清楚、有可用轮廓的照片；半身比硬截额头的头像更适合人物动作。抠像边缘、发丝、白边与阴影应在最终尺寸检查。处理图片使用当前环境的适用工具，遵守其编辑要求。
- 有环境信息的照片可保留大幅照片构图，不必全部抠透明。近景与宽景能连续说明关系时，优先用同一张/组照片保持对象连续。
- 阴影、边缘光、颜色与透视服务于层次；少量环境暗化帮助读字，不把所有照片压成同一种暗绿色。

## 三种可复用动作

以下数值是起点，按句长、画幅与目标帧率调整；它们是构图方法，不绑定某个渲染库。

**人物进入。** 在说到人物时开始出现，约 0.3–0.6 秒完成位移和轻微缩放，减速落稳；轻回弹可选，不让每张图都弹跳。保留五官与轮廓，主体停稳后给阅读时间。已有原帖截图时用头像建立身份、截图承载证据，避免再叠一整段标题。

**单人到群体。** 以照片中的单人局部建立“每人”，随后拉开构图或错开出现群体照片表达“许多人”。通过尺度、遮挡与轻微视差形成远近；不把同一孩子复制几十次伪装成真实群体。数字在被说到时进入，照片推进不能提前透露下一段结论。

**实物展开与飘落。** 仅用于台词确实涉及价值、分配或物件数量的段落：

- 扇形展开可从 5–9 张实物图开始，每张错开约 0.03–0.06 秒，围绕共同支点展开，旋转约 ±25–40°；用阴影、前后遮挡和 0.4–0.7 秒减速表达“由少到多”。不是排成等距卡片后整体滑动。
- 飘落分远、中、近三层，分别变化尺寸、初始位置、下落速度、摇摆相位和翻转方向。透视压缩、轻弯曲可体现纸张；近景少量虚化，远景较小较慢。随机参数固定种子或预先采样，不能每帧重抽造成抖动。
- 粒子数量服从画面空间，不能用满屏钞票掩盖主体。由聚拢到展开、再少量飘落即可，不要求整段持续下雨。画中画、字幕、金额和单位留在受保护区域。
- 先明确股票/份额，再以钞票作价值比喻；不能把“计划”“估算价值”剪成“已经发钱”。不同币种意象需要明确金额单位与估算性质，容易误读时改用对应币种或真实股权资料。

声音可在展开、落点、数字揭示处配低电平纸张声、短促滑入声或轻敲击。使用有来源依据或自行制作的声音，避免直接借用参考片配乐；不按切镜次数机械铺音效，对白始终清楚。

## 合成、清场与验收

推荐层级：底图/实景 → 后景实物 → 中景对象 → 前景粒子 → 数字、单位及必要底衬 → 真人画中画 → 来源/说明 → 最后字幕。位置仍需避让；把标签放到高层不能解决标签挡脸的问题。人物与场景需要交错时调整层级，但关键内容始终受保护。

同一语义状态只保留必要信息。进入下一金额/数量结论时，让上一个标签先退场或并入有意义的比较，不留下旧数字被纸币半遮半露。单位同数字一起检查；白字碰浅色纸币时用紧凑深色底衬、阴影或换位置，不只把字号加大。

| 检查 | 合格表现 | 需要返工 |
| --- | --- | --- |
| 语义 | 看图能认出对象，动作解释数量/关系 | 只觉得“科技感”，不知图片与台词何关 |
| 文字 | 图像承担名词，少量标签补数字与限定 | 同一人同时有头像、姓名巨字、重复标题 |
| 材质 | 清晰实物、自然照片、协调阴影和透视 | 简笔人形、统一荧光方框、切边或悬浮阴影 |
| 动作 | 入场 → 变化 → 停留/退场有信息节奏 | 全体同速同向、持续弹跳、无意义缩放 |
| 遮挡 | 密集阶段也能读单位、看人脸和字幕 | 钞票盖住旧标签、来源、发顶或嘴部 |

从最终 MP4 检查每种动作的入场、中段、最密集阶段和退场，兼看全尺寸与约 360 px 手机缩略画面；不能只挑最好看的一帧。与上一版同一语义段比较主体占比、层次、可读性与节奏。完整解码、同步和声音检查仍按 [render-and-qa.md](render-and-qa.md)，如未连续试听则如实记录。
