# 视觉语言与构图

## 真正的人后文字

背景先调色并绘字，再使用 alpha 将同一时刻的原始人物像素叠回。alpha 为 0 的地方显示背景与字；为 1 的地方显示原人像；边缘过渡保留发丝。色彩计算可写为 `out = foreground * alpha + background_with_text * (1-alpha)`。

不要把整个画面都调成蓝脸，也不要给字体简单加一个矩形洞冒充人物遮挡。静态人像抠图只能用于静态封面，不能代替正在讲话、抬手的人物视频。

RVM 连续推理维持四个 recurrent states；换镜头或换人物时清零。渲染、遮罩、裁切、变速必须共享帧映射。字幕烧录前后都可能影响抠像，因此优先从干净画面获得 matte。

## 1920×1080 横版起点

| 元素 | 起点 | 选择依据 |
| --- | --- | --- |
| 标题字重 | Noto Sans SC 900 | 粗实、稳定；变量字体显式设 wght |
| 中文标题 | 300–440 px | 2–4 字居多，左右错落绕开脸 |
| 英文字母 | 如 AI 约 500–600 px | 拉开主次，按实际字宽调整 |
| 标题颜色 | RGB 249,249,247 | 略暖白；只在有意义时少量强调色 |
| 标题阴影 | 模糊约 9 px、下移约 8 px、低透明 | 只辅助分层，不做粗黑轮廓或强发光 |
| 背景调色 | RGB gains 0.67/0.71/0.79；offsets 0/4/12 | 本案房间可用的起点，不是每个源片的 LUT |
| 入场 | 约 0.18–0.25 秒淡入，向上轻移约 18 px | 在说到关键词时完成，不做弹跳或持续漂浮 |
| 字幕 | Noto Sans SC 500、52 px、字距 4 px | 可在手机缩略图中读清，按真实字体测量 |
| 字幕底 | 高 88 px、左右各约 34 px 内边距、半径 44 px | 宽度随内容变化，深灰 RGB 13,16,22 / alpha 150 |
| 字幕位置 | 水平居中，顶边 y=952，底边 y=1040 | 该横版工程起点，新构图避开手势和操作结果 |

背景可以仅在真人段调色。素材或演示录屏保留其信息辨识度，不为了统一蓝调而改变产品画面颜色。

## 文字编排

- 每个关键词写明 `spoken_anchor`、开始/结束时间、位置和用途。优先一句一个重点；同一句有因果或递进时依次揭示。
- 一侧 2 字、另一侧 2 字是可用构图，并非固定模板。人物靠边、双人访谈或抬手占空间时重新布局。
- 人物挡住部分字建立层次，但仍要一眼认出完整意思。若只剩零碎笔画，移动或缩短文字；不要在字上方再贴一个解释标签补救。
- 同一词可以在人后做强调，同时底部保留对白字幕，但不要把整句复制到三个位置。
- 原参考中超大字可以贴近画边；新视频先保留约 5% 边距。确有构图需要才允许裁字，并逐字查看是否可识别。
- 字幕短句自然换段，专有名词、语义单位不断开；逐个测量实际字宽。长句优先拆 cue，不机械缩小到难读。
- 圆角底是轻量辅助，不做荧光黄绿小标签、大黑框或厚描边。底下可做局部 4 px 模糊；模糊只限胶囊区域。

## 三种镜头的切换

真人镜头强调“投标 / 太烦”；讲工作原理时切入“资料 → 处理 → 文档”的语义流程；讲真实操作时展示实际录屏。这是表达分工，不是要求每条片都出现相同三段或相同文案。

流程面板：真实房间低频柔化、轻暗色覆盖、有限文字和明确连线，按语音顺序揭示。超过数秒的图解应有信息推进，而不是仅漂移、闪光。操作标签可放在原生留白区；不得挤占关键按钮或结果。

## 需要修正的信号

- 字在发丝、脸、眼镜或抬起的手上漏出来：检查 matte 同步和边缘，不用更重阴影掩盖。
- 肩膀外缘白边、发丝闪烁：查看连续帧，修遮罩/分辨率或把字避开高风险边缘。
- 标题过大却像薄宋体：检查变量字体轴或是否误用常规字重。
- 人脸形状被“优化”：改用原始人物像素，视频包装不需要生成式重绘人物。
- 感觉卡顿：先排查剪掉字尾、句中微小间隙连续硬切、字幕反复闪断，再考虑转场；不要用频繁缩放遮掩。
