# 人物背后大字精剪

目标是可直接观看的正式 MP4：真人负责表达，背景巨字强调当前观点，真实素材与图解帮助理解，底部字幕承担完整听读。复用剪辑语言，不复制参考博主的形象或未经核验的观点。

## 从已有工程接着做

- 先找原片、干净画面、EDL、逐词转录、字幕、抠像缓存与最近交付版。用户修改已有成片时只改所需部分，保留之前已确认的剪口、音轨处理和打码。
- 比例优先服从用户和已有工程。本方法的视觉起点为 1920×1080 横版；其他比例重新构图，不直接套用横版坐标。
- 已精剪视频仅做包装时默认保留原声、时长和叙事；原片先完成自然对白剪辑。保留源文件和旧版，另存版本目录。
- 完成自检后直接交付正式 MP4，不额外设置预览审批环节。此技能不包含账号发布或 GitHub 上传。

## 先剪顺，再加字

删除失败开头和重说时，优先使用后面完整、顺畅的一遍。按完整语义段剪，保留字尾、辅音、必要呼吸和情绪停顿；不要机械删掉所有气口。

记录删段和原始帧到成片帧的对应关系。音频、字幕、关键词、演示录屏、人物遮罩及隐私遮罩使用同一时间轴。只改画面时尽量复制原音轨；改了口播长度就同步更新所有依赖时码。

用户指出口误时同时检查声音与字幕，不能只把字幕改对、声音仍说错。优先找原素材中的正确录音；确需本人音色局部补音时限定于本次纠错范围，记录实际合成区间，不默认合成全片、不借用参考博主声音。具体剪口与局部修订见 [references/edit-and-deliver.md](references/edit-and-deliver.md)。

## 分层合成是核心

按以下顺序合成：

1. 轻度调暗、偏冷的原始房间背景。
2. 与当前口播对应的巨大白色关键词及轻阴影。
3. 通过连续帧人物 alpha 叠回的原始人物像素。
4. 需要的资料画面、图解或演示提示，以及相应局部隐私处理。
5. 最后绘制底部对白字幕。

人物头发、脸、衣服和手势应真实挡住字。肤色沿用原片，不用生成式换脸、瘦脸或静态人像代替视频前景。遮罩随动作连续，镜头切换时重置时序抠像状态；抠像跟不上时改排字位置、改用资料镜头或先修遮罩，不交付明显穿帮的遮挡。

大字通常只承担 2–6 字关键词，出入点跟随说话内容；不是逐字放大的字幕，也不是长期挂在左上角的标签。人后巨字、完整口播字幕、录屏操作提示是三种不同层级。

完整字体、布局、入场和边缘质量要求见 [references/visual-language.md](references/visual-language.md)。本地已跑通的字体起点：标题 Noto Sans SC 900；字幕 Noto Sans SC 500、52 px、字距 4 px、88 px 高半透明深灰圆角底。数值适用于 1920×1080，不能跨比例照搬。

## 画面必须解释台词

根据语义切换三种画面：

- **观点与态度**：真人＋人物背后的关键词。
- **对象与证据**：实际产品、评论、资料、录屏。文字或操作太小时放大所指区域，保留必要上下文。
- **关系与流程**：柔化的真实画面背景＋克制的透明深色面板，依次揭示输入、处理、输出；示意图不能冒充真实产品结果。

优先用户素材与可核验的真实对象。不要拿泛科技立方体、芯片、机器人充当任何 AI 业务；说“企业资料生成文档”时，应看得出资料、处理动作和生成结果。新素材缺乏具体信息时保留真人，比硬塞无关装饰更合适。

演示压缩等待、重复操作和冗长滚动，保留观众能理解的操作与结果。人物表情、完整动作、关键界面先于固定切镜频率。字幕与隐私要求见 [references/edit-and-deliver.md](references/edit-and-deliver.md)。

## 可运行的基础包装器

已有 Remotion、HyperFrames 或 FFmpeg 工程可直接续用，不强制换技术栈。需要复用本次 Python 合成法时：

- 复制 [assets/style-template.json](assets/style-template.json) 到当前项目，改素材路径、真人区间、标题锚点与字幕。
- 按 [references/renderer.md](references/renderer.md) 使用 [scripts/behind_titles.py](scripts/behind_titles.py)。它提供 RVM 连续抠像与背景巨字/字幕合成，输入为已剪顺、已归一化的干净视频。
- 包装器不替代对白取舍、资料搜集、B-roll 编排或隐私跟踪；这些先在项目内完成。模型和字体由现有环境提供，技能不携带视频、人物录音或模型权重。

## 检查并交付

看最终编码文件，不能只看设计预览：检查首尾、所有文字入出点、抬手/转头、发丝边缘、演示切换与打码变化；缩到约 360 px 宽检查大字是否仍可读。完整解码、音画时长、帧率、字幕溢出和隐私遮罩都要检查。

确认关键词没有被人物挡到无法辨认、脸上没有漏字、手势不会穿字。检查声音剪口、口误和字幕同步；ASR 和响度数据只能证明各自检查结果，不能冒充人工试听。

输出正式 MP4，并在项目中保留字幕、EDL/帧映射、样式配置、来源和检查记录。封面、发布文案仅在用户要求时另做；真人封面也应参考原始照片，避免经过多次生成后改变脸型。

本次“AI 应标挑战”的实现位置与正反例见 [references/local-example.md](references/local-example.md)，只在需要比对或续改该项目时读取。案例内容和打码词不作为新视频默认值。

调用示例：`$behind-person-titles 按上次背景大字的剪法做这条横版口播，删掉前面重录失败的部分，保持说话连贯，直接输出正式 MP4。`
